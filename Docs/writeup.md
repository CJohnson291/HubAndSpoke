# <h1 align='center'>Hub and Spoke project</h1>

### <h2 align='center'>Project goal</h2>
### To build, test, and codify a secure, cost-effective hub-and-spoke cloud architecture in Azure that demonstrates networking controls and a content promotion pipeline from non-prod to production

#### Plan
- Hub and spoke Vnet topology with peering
- Forced routing through a custom Linux router using IP forwarding and UDRs (replacing a managed firewall to reduce costs)
- Non-prod staging storage to prod storage test
- Azure CDN with Private Link for edge delivery
